# JavaScript Arithmetic Library

A simple JavaScript project created as part of my Industrial Information Technology studies at LAB University of Applied Sciences.

The project demonstrates basic JavaScript modules and unit testing with Mocha and Chai.

## Features

The `mylib` module provides four arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling

## Project Structure

- `mylib.js` – arithmetic functions
- `main.js` – demonstrates the library
- `tests/mylib.test.js` – unit tests using Mocha and Chai
